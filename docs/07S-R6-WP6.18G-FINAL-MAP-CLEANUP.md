# R6-WP6.18G - Final Playthrough Map Clean-up

## Trigger

A second human mobile playthrough after R6-WP6.18A-F confirmed that the main remediation cycle had materially improved the game, but three presentation defects remained visible:

- Pebble still appeared inside a beige circular placeholder despite the production NPC marker clean-up;
- the new Rainbow Meadow route to Crystal Brook branched too late and crossed through the Ribbon Board area;
- production region gateways still showed legacy R5 destination signs behind the newer authored cave, woodland and race-gate presentation.

R6 remains at the mandatory WP6.18 human-feedback hard stop. R7 is not released by this package.

## Root causes

### Pebble

R6-WP6.18F correctly hid the original `SunbeamVillageScene` prototype marker circle and icon. The remaining circle came from a separate older `PebbleCollectionWorldManager` presentation that independently created a beige cover and rock icon at Pebble's position. The production Pebble art was therefore present, but obscured by a second legacy presentation layer.

### Crystal Brook meadow route

R6-WP6.18D2 started its authored route at approximately the race-hub approach and then ran diagonally through the Ribbon Board footprint. The route was visually distinct from the Rainbow Run entrance, but its branch point and geometry were not credible as a world path.

### Duplicate gateway names

R5 gateway containers remain authoritative for transition zones, proximity prompts and race interaction. D2 correctly added production gateway art on top, but the old static sign text inside those functional containers remained visible underneath the new labels.

## Implementation

- Keep the existing R5 gateway containers and interaction zones intact.
- Hide only the obsolete static R5 sign label at each production-upgraded gateway.
- Keep proximity prompts and race lock/help text operational.
- Suppress Pebble's separate story-system beige cover and rock icon while retaining its talk prompt, pointer zone and story routing.
- Replace the D2 Rainbow Meadow to Crystal Brook path presentation with an earlier branch from the main meadow path at approximately `(1900, 1040)`.
- Route the branch south and around the Ribbon Board before curving back to the existing Crystal Brook cave at `(3030, 1750)`.
- Hide the old D2 path/divider presentation rather than changing traversal, collision, gateway or save coordinates.

## Regression coverage

Automated coverage verifies that:

- production Pebble remains visible while the legacy story cover/icon are hidden and the talk prompt remains available;
- the obsolete D2 meadow path is hidden and the corrected branch is visible;
- corrected route geometry branches before the Ribbon Board and stays outside an expanded board footprint that includes path width;
- all production-upgraded region gateways hide their corresponding R5 static sign labels;
- the authored R6 cave/threshold/gate objects remain present.

## Boundary

This package does not change:

- save schema or migrations;
- quests, friendship or story progression;
- economy or inventory;
- region transition destinations;
- collision geometry;
- race unlocks, physics or balance;
- mobile control behaviour.

## Acceptance

R6-WP6.18G is complete when validation is green and the three reported visual defects are absent in the deployed build. The WP6.18 hard stop remains active until another human playthrough explicitly releases R7.
