# R6.5-WP19H2.10 – Unlock & Reward Framework

## Purpose

Turn the cottage customisation catalogue into a progression-ready reward system without coupling quest or shop logic to cottage rendering.

## Accepted prerequisite

R6.5-WP19H2.9 was explicitly human-approved by David on 19 September 2026. H2.0 through H2.9 are therefore preservation requirements for this checkpoint.

## Product model

Home styles now have two entitlement classes:

- **Starter** options are available immediately on a new game.
- **Unlockable** options remain visible in the style editor but are marked `LOCKED` and cannot be selected until granted.

The starter set deliberately keeps multiple choices in every major area so customisation is useful immediately. Unlockables add progression breadth rather than making the starting cottage feel incomplete.

## Architecture

- `home.unlockedStyleIds` is the canonical persisted entitlement list.
- Save schema v7 introduces that field.
- The v6 → v7 migration grants the starter set and also grandfathers any currently selected known style so an existing save can never lose its appearance.
- `CottageStyleEntitlementService` is the single grant/check owner for home-style entitlements.
- `grantStyle` and `grantStyles` accept sources of `quest`, `reward`, `shop`, `system` or `diagnostic`.
- Successful grants emit `HOME_STYLE_UNLOCKED` for reusable feedback/telemetry hooks.
- `CottageStyleService` remains the canonical style persistence owner and now refuses a newly selected locked option.
- Cottage presentation knows only whether a style is unlocked; it contains no quest or shop-specific rules.
- Later quest and shop packages can call the same entitlement service rather than introducing parallel ownership state.

## Starter catalogue

Immediate starter options include:

- Moon Cream, Blush Dawn and Misty Lilac wall colours;
- Plain and Moon Sprigs wallpaper;
- Honey Oak and Rosewood flooring;
- two finishes for each customisable furniture family.

## Unlockable catalogue

Progression-ready options include:

- Sea Glass and Buttercup wall colours;
- Star Scatter and Meadow Vines wallpaper;
- Whitewashed Oak and Lavender Boards flooring;
- one additional finish for each customisable furniture family.

## Human simulation hook

For H2.10 qualification only, diagnostics mode accepts a `homeStyleUnlock` query parameter. This invokes the same production entitlement service with source `diagnostic`; it is not a second persistence path.

Example:

`?diagnostics=1&homeStyleUnlock=cottage-wall:sea-glass`

This provides a repeatable human/browser gate without prematurely assigning a specific quest or shop to the reward.

## Validation requirements

- starter options are available on a fresh save;
- unlockable options are visibly locked and cannot be selected;
- granting an unlock persists it exactly once;
- quest/reward/shop callers can use the same service API;
- an unlocked option becomes selectable and persists after application/reload;
- schema-v6 saves retain currently selected unlockable styles;
- H2.6 surface styling and H2.7 furniture variants continue to work using starter options;
- existing H2.0–H2.9 behaviour remains unchanged.

## Human gate

1. Open the cottage style editor on the ordinary preview and confirm Sea Glass is visibly locked.
2. Use the H2.10 diagnostic unlock preview for `cottage-wall:sea-glass`.
3. Re-open the style editor, confirm Sea Glass is available, apply it to a wall and leave the editor.
4. Reload/Continue and confirm both the entitlement and selected wall colour persist.
5. Confirm the lock presentation is understandable and does not make the starter catalogue feel artificially sparse.

Do not start H2.11 until this gate is explicitly approved.
