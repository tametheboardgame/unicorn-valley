# R6.5-WP19H2.0 – Cottage Architecture & Cleanup

## Purpose

H2.0 establishes stable ownership and authored world anchors before the Moonflower Cottage is visually rebuilt. The room remains on its existing geometry in this checkpoint so H2.1 can change layout without forcing story/content systems to copy new coordinates.

## Canonical ownership

- `src/game/world/CottageSemanticAnchors.ts` owns named authored world points used by cottage navigation, systems, visitors and protected future story space.
- `src/game/world/CottageInteriorMap.ts` owns the current room bounds, collision rectangles, decoration slots and map interaction geometry. Door and Wonderbook points resolve from the semantic anchor registry rather than copying coordinates.
- `src/game/scenes/CottageInteriorScene.ts` owns current cottage presentation and ordinary room interactions. H2.0 removes the floor moon glyphs and the redundant door caption here at source.
- `src/content/r4FriendVisits.ts` owns visitor eligibility/content and now references semantic anchor IDs rather than world coordinates.
- `src/game/home/CottageFriendVisitManager.ts` owns visitor presentation/dialogue integration and resolves visitor world positions through the semantic anchor registry.
- `src/game/home/HomeDecorationService.ts` and the existing home save state remain the canonical persistence path for placeable cottage decorations. H2.0 does not create a parallel home system.

Current system anchors:

The coordinates in the registry are authored world coordinates for the current H2.0 room. H2.1 may reposition them while changing the room shell. Consumers must continue to bind by anchor ID rather than copying coordinates.

## Story migration boundary

H2.0 creates the canonical egg-nest and future story anchors but deliberately does not perform the final strange-egg relocation. The H2 delivery plan assigns final egg and protected story-object placement to H2.9, after the room shell, furniture and physicality passes have stabilised. Existing egg behaviour must therefore remain unchanged at this checkpoint.

Visitor positions are safe to consolidate now because their current locations are preserved exactly while only coordinate ownership changes.

## Source cleanup completed in H2.0

- The four decorative floor moon glyphs are no longer created by `CottageInteriorScene`.
- The rendered `Moonflower Glade` caption above the door is no longer created.
- The exit interaction itself remains intact and resolves through `cottage.door`.
- The Wonderbook world prop and interaction resolve through `cottage.wonderbook`.
