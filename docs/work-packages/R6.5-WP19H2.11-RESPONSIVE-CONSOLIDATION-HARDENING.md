## Consolidation scope

- CottageInteriorScene is the canonical owner of finished cottage interactions and publishes them
  through the shared SceneInteractionRegistry / WorldInteractionCoordinator.
- The retired CottageDepthWorldManager is removed rather than hidden. Its useful sofa, fireplace,
  window and companion-corner interactions are preserved using canonical cottage layout geometry.
- Sleep, exit, Wonderbook, treasure, friend visits and decoration targets share one interaction route.
- Decoration spots retain direct tap/click editing while their visual halo and sparkle are presentation
  only, preventing overlapping input surfaces.
- Cottage event subscriptions use the canonical scene lifecycle scope.
- Reduced Motion suppresses decorative cottage marker, reward and visiting-friend idle animation while
  preserving all interaction state.
- Portrait touch receives DOM companion controls for both the decoration collection and Room Style
  editor, reusing the established accessible modal companion rather than creating a second responsive
  UI system.
- Existing save schema v7, style entitlements, furniture variants, decoration ownership/placement,
  story anchors, sleep/time behaviour and H2.0–H2.10 geometry remain authoritative.

## Regression hardening

- Keep semantic/stable browser selectors; do not reintroduce coordinate ownership into runtime code.
- Split the legacy tablet creator/exploration/Book/accessibility mega-journey into bounded contracts so
  CI duration variance cannot turn a passing feature into a four-minute monolithic timeout.
- Preserve the Crystal Cascade gameplay contract. If its existing browser timing check fails on the
  final head, diagnose the exact failure before changing either race balance or test timing.
- Do not weaken unrelated coverage to make the gate green.
