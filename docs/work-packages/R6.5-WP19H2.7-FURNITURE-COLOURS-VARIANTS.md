# R6.5-WP19H2.7 – Furniture Colours & Variants

**Status:** In progress

**Parent package:** R6.5-WP19H2 – Moonflower Cottage & Home Customisation

**Previous checkpoint:** H2.6 Walls, Floor & Wallpaper, human-approved 18 September 2026.

## Purpose

Let the player personalise selected permanent cottage furniture without changing room geometry, collision, sleep behaviour or semantic interaction anchors.

## Implementation decisions

- Extend the existing versioned `home.style` state rather than creating furniture-specific storage.
- Add independent named variants for the bed, sofa, tea-table/chair set and fireplace.
- Preserve the exact approved furniture geometry and collision footprints; H2.7 variants change finish/palette only.
- Keep current H2.2 visuals as the migration/default variants.
- Add a fourth `Furniture` category to the existing Room Style editor rather than creating another modal.
- Furniture editing uses an explicit furniture selector followed by directly tappable variant swatches, matching the established Unicorn Designer / Room Style interaction language.
- Variant IDs are stable catalogue IDs. Presentation names/descriptions stay editor-only so future variants can be added without inflating startup unnecessarily.
- Keep the catalogue independent from quest/shop logic. H2.10 will own entitlement/unlock rules.
- Unknown/retired furniture variant IDs resolve visually to the canonical default without corrupting persisted state.

## Starter variant target

- Bed: Moonflower, Rose Dream, Sea Glass.
- Sofa: Sage, Berry, Starlight.
- Tea set: Honey Oak, Rosewood, Whitewashed.
- Fireplace: Warm Stone, Moonstone, Rose Stone.

## Acceptance criteria

- Save schema migration adds explicit furniture-variant state without changing the appearance of existing saves.
- Bed, sofa, tea set and fireplace can each use a different named variant simultaneously.
- Changing a variant does not alter furniture position, dimensions, collision or semantic interaction anchors.
- The Room Style editor exposes a Furniture tab with clear furniture selection and visible variant swatches.
- Live preview reflects the selected furniture variants before Apply.
- Back/cancel does not persist preview-only variant changes.
- Apply persists all surface and furniture style state together.
- Furniture variants survive cottage exit/re-entry, Continue and browser reload.
- Additional catalogue variants can be added later without changing the editor layout contract.
- Variant presentation has no direct dependency on quest IDs, shop IDs or reward-specific logic.

## Human gate

Change at least three different furniture items to different variants, Apply, walk around and use the bed, then leave/re-enter and reload. Confirm appearance persists while collision, layering and sleep remain unchanged.
