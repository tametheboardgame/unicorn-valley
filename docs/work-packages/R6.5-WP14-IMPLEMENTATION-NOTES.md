# R6.5-WP14 Implementation Notes

## Activity roster

The non-racing repeatable activity target is met by three deliberately different activities:

1. Firefly Lantern - existing reflex/attention activity.
2. Maple's Wobbly Baking Table - expressive three-choice cake design.
3. Coral's Beachcombing Notebook - slow observation activity with nature-friendly exploration.

## Progress model

WP14 intentionally uses finite collection progress rather than grindable score or currency loops.

- Bakery record: `minigame:maple-baking-table`, maximum meaningful progress 3 cake styles.
- Beach record: `minigame:coral-beachcombing`, maximum meaningful progress 3 notebook pages.
- Each activity awards the existing first-activity Shimmer amount once through `EconomyRewardService`.
- Repeating an already-known result does not add another discovery or another first-completion reward.
- No timer, streak, daily reset or real-world wait is introduced.

## Existing hooks preserved

- Maple's original Wobbly Cake Plan remains the authored story-sized cake hook. The new repeatable table appears only after that quest is complete.
- Coral's original Beachcombing Basket remains its short first-introduction/observation interaction. The deeper Beachcombing Notebook appears beside it once Coral's Beach story has unlocked beachcombing.
- Existing WP10/WP13 story managers are not patched or replaced.

## Loading

`RepeatableActivityEntryWorldManager` is dynamically imported by `main.ts`. The activity scenes themselves are dynamically imported only when the player starts them. This preserves the 520 KiB hard application-entry contract.
