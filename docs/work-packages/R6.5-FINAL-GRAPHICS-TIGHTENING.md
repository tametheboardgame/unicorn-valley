# R6.5 Final Graphics Tightening

## Trigger

Mainline playthrough feedback after the world-state / geometry polish pass identified a final set of visual-composition issues:

- a disconnected-looking path treatment at the Crystal Brook → Whispering Woods threshold;
- stacked translucent light/shadow shapes in Whispering Woods;
- sharp overlapping stream geometry in Crystal Brook;
- oversized high-alpha backdrop circles making Brook and Woods read as layered shapes rather than coherent terrain.

## Scope

This pass is deliberately visual only.

### Whispering Woods

- retain the canonical main exploration path all the way to the Brook threshold;
- suppress the later R6 short entrance-trail overlay whose endpoint does not meet the canonical route;
- retain one authored woodland light-shaft treatment and suppress the duplicate R6 shaft layer;
- reduce the opacity of the three large base backdrop circles so regional colour variation remains subtle rather than forming obvious overlapping shapes.

### Crystal Brook

- replace the original sharp-join shallow-stream graphics with a rounded three-band stream treatment using the canonical `CRYSTAL_BROOK_MAP.shallowStream` geometry;
- preserve the existing stream route, collision, stepping stones, discoveries and interactions;
- reduce the opacity of the three large base backdrop circles so banks, water and route art remain the dominant readable shapes.

## Guardrails

- no save or Continue changes;
- no collision changes;
- no quest/content changes;
- no route/topology changes;
- no performance-budget increase;
- the final tightening manager is lazy-loaded with the existing R6 presentation managers so the application entry bundle remains protected.

## Regression coverage

Browser coverage verifies that:

- the duplicate Woods entry trail is no longer visible;
- the duplicate Woods light-shaft layer is no longer visible;
- the canonical rounded path polish remains visible;
- Brook uses the replacement rounded stream while the legacy sharp stream graphics are hidden;
- the large Brook/Woods backdrop circles remain below the tightened opacity ceiling.
