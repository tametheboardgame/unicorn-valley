# R6.5-WP18F - World Consistency, Visual Quality and Experience Improvements

## Objective

Address the non-shell world-consistency, character-presentation, environmental-readability and selected daughter-led experience issues exposed by the WP17 playthrough, while preserving areas and activities that already received strong positive feedback.

This is a targeted quality/experience package, not a licence for indiscriminate art replacement.

## 1. Core-cast authoritative presence/activity state

Create a reusable authority for recurring friend characters who participate in multiple places, quests and activities.

The system should be able to answer, for an applicable core NPC:

- where is this character now?;
- what activity/state are they currently in?;
- can they participate in another event right now?;
- what representation should be rendered in the current scene?;
- what happens when progression changes their schedule/presence?;
- how does save/continue restore that state safely?

### Nova as initial proof

Fix the observed contradiction where Nova can simultaneously:

- remain at the race area;
- appear at the picnic;
- visit the player's cottage;
- and be represented by symbols such as a star/race flag rather than her unicorn body.

A core character must not occupy mutually exclusive activities/locations at once.

Do not overbuild a full life simulation for every ambient NPC. The system should first cover the recurring cast whose multi-system involvement makes authoritative presence worthwhile.

## 2. Character representation cleanup

Audit characters that can appear as circles, symbols, flags or other placeholder-like representations.

Rules:

- world-space friend/NPC presence should normally render the actual character/unicorn presentation;
- map or compact UI icons may use symbols when clearly UI rather than world bodies;
- no symbol should imply a character is present while the same character body remains authoritatively elsewhere unless this is deliberately a non-presence UI marker.

Pip and any other "ball/circle" presentations highlighted by human play require explicit visual review.

## 3. Unicorn neck/mane visual correction

Review player and NPC unicorn anatomy/presentation, particularly the neck/mane relationship.

Human feedback:

- more mane coverage improves the silhouette;
- exposed neck can look wrong/saggy;
- the issue is perceptual, so do not assume one numeric proportion tweak is automatically sufficient.

Create bounded visual comparisons where needed, then update the reusable unicorn presentation so the improvement applies consistently without breaking animations/customisation.

## 4. Shell Cove identity

Rework the location cues so Shell Cove convincingly reads as a cove.

Consider coastline enclosure, curved land/water shape, framing rocks/cliffs/dunes, shell features and approach composition. Preserve existing gameplay paths/content unless geometry change is necessary and tested.

The acceptance question is visual/geographic: would a child looking at it plausibly call it a cove without being told the name?

## 5. Crystal readability and Crystal Brook approach

Improve ambiguous triangular crystal/stalactite forms into recognisable magical crystal/geological forms.

Also revisit the Crystal Brook entrance/approach so it feels like travelling along a path toward a cave/grotto/crystal destination rather than encountering an awkward gateway beside unrelated race content.

Preserve navigation and collision correctness while improving visual signposting.

## 6. Sunbeam Village shops/place quality

Complete a targeted visual/place pass on shops so they read as interesting destinations rather than weak façades.

Priorities:

- distinct identity per shop;
- readable entrances;
- convincing exterior-to-interior relationship;
- shopkeeper/interaction presentation;
- signage/props/scenery that communicate function visually;
- no return to placeholder-looking blocks or excessive floating labels.

## 7. Preserve and selectively deepen positive areas

### Rainbow Meadow

Human feedback was positive. Preserve its successful look unless a specific functional change requires adjustment.

### Whispering Woods

Preserve the liked baseline. A bounded magical-atmosphere enhancement may add subtle particles, lighting, colour, foliage or interaction detail if it strengthens the existing area without hurting performance/readability.

### Tree Nook mushrooms

The mushrooms were specifically loved. Add a lightweight meaningful interaction if it can be done without destabilising the area, for example inspect/reaction/discovery/collectible behaviour consistent with existing systems.

Do not turn every decorative object into a mechanic.

## 8. Daughter-led small content candidates

Evaluate for bounded inclusion when low-risk and coherent:

- unicorn sandcastles at the beach;
- interactive mushrooms;
- additional magical visual detail in Whispering Woods.

Larger ideas such as Unicorn Palace and multi-step party/event systems should be retained as R7/backlog candidates unless a specific small precursor is justified here.

## Quality rules

- Prefer reusable character/world presentation systems over scene-specific patches.
- Preserve frame/performance budget and visibility of important paths/interactions.
- Do not remove successful visual identity merely to impose consistency.
- Any geometry/collision change receives route/walkability regression coverage.
- Visual approval may use screenshots/concept comparisons before committing a major art-direction change.

## Acceptance

WP18F is complete when core recurring NPC presence is coherent, Nova no longer duplicates across mutually exclusive states, placeholder-like world representations are cleaned up, unicorn neck/mane presentation is materially improved, Shell Cove and Crystal areas read more convincingly, shop destinations are stronger, and selected positive/daughter-led improvements have been added without damaging the areas she already liked.
