# R6.5-WP12 Implementation Notes

WP12 keeps the established shared `RaceScene` and adds breadth around it rather than introducing a second racing stack.

## Shared course contract

The regular course roster is exactly five courses:

1. Sunrise Sprint
2. Crystal Cascade
3. Petal Parade
4. Mooncap Trail
5. Shoreline Surge

Nova's First Run remains tutorial-only and is not part of the Rainbow Cup.

## New course identities

- Petal Parade uses a dense flower-hurdle rhythm, Petal Breeze / Rainbow Petal Stream boosts and nine petal sparkles.
- Mooncap Trail uses roots and fern gates, fewer collectables, darker woodland presentation and the shared-architecture Root Hop shortcut.
- Shoreline Surge uses driftwood, dune-grass / shell-marker gates, tide and sea-breeze boosts, and Skipper's route-ready flag as its story gate.

## Rainbow Cup

The Cup reads the existing race records and progression state. A course counts once it has a positive saved best time. Placement does not matter.

Finishing the fifth regular course:

- sets the Rainbow Cup completion world flag;
- unlocks the Rainbow Cup Wonderbook discovery;
- grants one Rainbow Cup Pennant decoration;
- remains idempotent on repeat races.

The Meadow Cup view shows all five events, completion/best-time state and lock clues. Cup-launched races return to the Meadow hub and reopen the Cup view. Direct Mooncap and Shoreline races return to their originating region.

## Performance and compatibility

The regional/Cup manager is dynamically imported from `main.ts` so the additional world integration does not become static application-entry weight. All new courses continue to use the existing keyboard, touch, NPC competition and race-assistance code in `RaceScene`.

No save-schema change is introduced and the 520 KiB application-entry budget remains unchanged.
