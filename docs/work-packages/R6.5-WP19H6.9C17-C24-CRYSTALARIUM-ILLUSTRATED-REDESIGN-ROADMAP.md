## Supersession and non-negotiable constraints

- This roadmap **supersedes the presentation/economy proposals** in C11–C16 where they conflict: **remove** the separate Growing section, permanent shelf strip and standalone Offer button; make order cards themselves tappable Offer targets; use image-led rounded UI and real spotlight guide; implement horizontally scrolled multiple active order cards; represent any consumed growth resource as **Growth Potion**, *not* Crystal Energy. The earlier C13B separate producer-charge counter is **deferred/rejected as a default**: no dual-resource system.
- Keep C11B's actual allowed-action controller tutorial, C13A's three rooted 0/4/7-unlocked wells **outside all 42 sockets**, equal-family equal-tier merge rule, 18 crystal appearances/six tiers, 50 authored orders/five chapters, non-destructive Brook Wash, optional Harmony/Polish, H6.9B Grotto opening melody, in-cave quest and both entry points.
- Retain the **no-hard-wait** child-first promise: 50 orders must be achievable from empty/dry resource conditions without real-world time gating, payment, daily events or mandatory adventure world rewards. Offline/old-save/Just Games players must not be stranded by potion, full board or full storage. The new resource can pace the interface but must never remove a reliable free continuation.
- Do not change original Grotto unlocking, move established quests, fork the crystalarium engine, modify independent MG/Pond Leap PR #289, or edit root `STATUS.md` / `PROJECT_STATE.json` on World draft branch. Do not merge until user visual approval and authoritative H6.9D checks.
