# R6.5-WP18A - Landscape Tablet UX Concept and Approval

## Objective

Define and obtain explicit human approval for the new **landscape-tablet-first** interface/control direction before doing the expensive shell/control implementation work.

This package is intentionally concept-first. It may create design notes and visual concept images, but it must **not** implement the new gameplay shell, race controls, inventory layout or creator layout in production code.

## Product principle established

Unicorn Valley should feel like a game designed to be held and played on a landscape tablet, not a desktop browser game with touch buttons added around it.

The reference human-test device is Samsung Galaxy Tab S8, Chrome, landscape.

Desktop keyboard/mouse remains supported, but concept decisions first answer: "Is this clear and comfortable for a seven-year-old using a landscape tablet?"

## Required concept set

The user reviewed and approved four supplied visual directions covering:

1. normal exploration shell;
2. landscape race controls;
3. Bag/inventory plus Map access;
4. Unicorn Creator.

The supplied concepts intentionally use a much more expensive 3D presentation than the production browser game. Their **control layout, touch placement, screen occupation, hierarchy and interaction design** are the approved authority, not their rendering fidelity.

## Approved direction summary

- Exploration: compact top Map/Bag/Book/Settings navigation; lower-left movement control; lower-right contextual primary action and separate Gallop; bottom-centre contextual hint; world remains dominant.
- Racing: left/right steering lower-left; Jump and Gallop lower-right; compact progress/status at top; Pause top-right; central track remains clear; no browser-long-press dependency.
- Bag: large landscape modal; clear Food/Quest/Decor/Keepsakes categories; scrollable inventory; visual item quantities; selected-item detail panel; explicit Eat/use action; Bag and Map remain distinct.
- Creator: large preview occupying roughly half the screen; progressive Main/Colours/Mane & Tail/Horn/Markings/Accessories categories; only active group expanded; large visual options; clear Back/Randomise/Save actions.

Full durable contract: `docs/07AA-R6.5-WP18A-APPROVED-TABLET-UX-DIRECTION.md`.
