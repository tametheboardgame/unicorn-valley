## R5-WP5.9A implementation notes

- World interactables now share `WorldInteractionInput`, with non-consuming `E`/`Enter` press tracking plus pointer/tap binding. This avoids Phaser `JustDown` consumption when several world managers inspect the same press during one frame.
- Ordinary R5 region travel is movement-only. Crystal Cascade remains an explicit interactive race gateway.
- Dialogue/activity returns use `WorldArrivalState` plus the existing mutable map spawn points to preserve exact world position and facing without changing the save schema.
- Representative older Glade/Village/Meadow gateway spawn setters also establish sensible arrival facing.
- Collision-aware click navigation now includes Crystal Brook and Whispering Woods. Click navigation records player facing so later dialogue/activity returns remain correct.
- The exploration Controls panel is the current blocking modal for movement. It is identified explicitly rather than by UI depth, so transient feedback/toasts do not incorrectly freeze movement.
- `GALLOP` is a named input action. Keyboard default is held Shift, touch has an equivalent held control, and outdoor exploration uses the locked 1.6x speed multiplier through `PlayerEntity`, preserving normal Phaser collision/transition handling.
- No save-version change or migration was required for WP5.9A.

## R5-WP5.9B implementation notes

- The former exploration HUD ownership hidden inside `InteractionPrompt` has been split into a dedicated per-scene `ExplorationShell`. Interaction prompts now remain local interaction UI only.
- The shell owns Bag, Sound, Controls, suggestion/Hint, reward feedback and the shared touch pad. `ExplorationShell.ensure` makes shell creation idempotent so managers and older scenes cannot duplicate the common chrome.
- All current free-roaming exploration scenes use the same shell contract, including Crystal Brook and Whispering Woods. Story, race and activity scenes remain outside the shell allow-list.
- Crystal Brook and Whispering Woods retain their existing dedicated audio lifecycle; the shared Sound panel changes settings there without double-entering or double-leaving scene audio.
- Crystal Brook's two invisible middle-water blockers were removed because they crossed the visible stepping-stone/main-route corridor. The visible central stream is explicitly treated as shallow traversable water.
- The hard upper/lower pool collision rectangles were tightened inside the painted pools so the apparent banks and main path do not contain invisible rectangular corners.
- Brook and Woods route guidance is world-space rather than fixed HUD copy. The Brook text no longer implies a general exploration jump/hop mechanic.
- Geometry regression tests now protect major region spawns/gateway approaches, Crystal Brook stepping stones/main route and the Whispering Woods guiding-light route.
- No save-version change or migration was required for WP5.9B.

## R5-WP5.9C implementation notes

- `OutdoorWorldScenes` is the shared allow-list for Valley atmosphere/weather coverage. It currently includes Moonflower Glade, Moonflower Patch, Sunbeam Village, Rainbow Meadow, Crystal Brook and Whispering Woods; interiors, races and activities remain excluded.
- Automatic atmospheric time advances from Phaser game-loop elapsed time, not the real-world clock. Each state lasts 180 seconds and cycles Morning -> Afternoon -> Sunset -> Night -> Morning.
- Progression is retained only as the initial automatic-state seed for existing saves. Manual overrides keep the underlying automatic clock moving, so returning to Auto resumes predictably instead of silently resetting.
- Morning and afternoon use materially different cool-dawn versus warm-high-sun overlays plus distinct ambient light cues; sunset/night remain stronger states.
- Magical weather consumes the same outdoor-region registry and retains one global manual/Auto state across scene transitions.
- Rain remains a viewport weather layer. Sparkle weather is now a world-space recycled field around the travelling unicorn, with stale particles repositioned around the player rather than remaining glued to the camera.
- The existing Stardew Drop weather discovery remains Woods-specific and continues to depend on sparkle weather.
- No save-version change or migration was required for WP5.9C.

## R5-WP5.9D implementation notes

- Crystal Cascade unlock state is derived from the established Nova/practice/Sunrise Sprint/race records instead of adding a new save-schema field.

- Prism Current is an optional course shortcut with meaningful race progress, while the ordinary ground route and NPC race completion remain viable.
- Crystal Cascade now carries Crystal Brook water/current/crystal presentation rather than reading as a renamed Sunrise Sprint.
- Race result/reward identity and Crystal Brook return handling remain separate from Sunrise Sprint.
- No save-version change or migration was required for WP5.9D.

## R5-WP5.9E implementation notes

- Wonderbook discoveries are paginated into bounded two-page spreads so content cannot overflow underneath page controls.
- Previous/next controls use correctly directed pointer/touch handling plus the horizontal input abstraction for keyboard/controller-ready page turns.
- The Bag now has Items and Map tabs. The map marks the persisted current location, shows implemented physical routes as solid paths and keeps future routes anonymous/planned.
- `ValleyMapTopology` is the canonical topology source used by the Bag and later layout work; no fast travel was introduced.
- No save-version change or migration was required for WP5.9E.

## R5-WP5.9F implementation notes

- A new save unlocks replay modes only after a perfect eight-light Normal completion; legacy saves carrying the earlier first-completion memory remain compatible and receive the visible milestone state.
- Normal mode provides Gentle, Classic and Swift tiers through target lifetime/size tuning without changing the successful core interaction.
- Multicolour uses yellow targets, coloured decoys and a recoverable three-mistake limit.
- Endless mode progressively increases pressure, ends on a missed target and persists a personal-best streak.
- Finite Wonderbook milestones cover first Normal, first Multicolour and two Endless thresholds; repeat play does not create an exploitable reward grind.
- Firefly Lantern continues to use the unified Woods return-position contract from WP5.9A.
- No save-version change or migration was required for WP5.9F.

## R5-WP5.9G implementation notes

- The established story-region chain is preserved to avoid bypassing progression. Non-linearity comes from real optional destinations already present inside the regions rather than invented cross-region shortcuts.
- Moonflower Field, Rainbow Run, Prism Grotto and Lantern Clearing are explicit physical side nodes in the canonical Valley topology.
- Glade, Meadow, Brook and Woods receive world-space branch signposts pointing towards those optional destinations. The signs are orientation cues, not UI markers or new compulsory interactions.
- Every current major region records a concrete revisit reason based on existing systems such as friends, discoveries, races, activities, weather or home content rather than manufactured grind.
- The Bag map resolves a physical route towards Moonflower Cottage and shows the next region home alongside the current region's nearby/revisit cue.
- Geometry presentation now uses a per-scene anchor rather than a permanent `WeakSet`, ensuring guidance and branch signs are reconstructed after a Phaser scene restart/revisit.
- Future planned paths remain anonymous and non-traversable; no fast travel is introduced.
- Unit/browser regression coverage protects map/world agreement, non-linear side branches, homeward routing, branch cues and revisit metadata.
- No save-version change or migration is required for WP5.9G.
