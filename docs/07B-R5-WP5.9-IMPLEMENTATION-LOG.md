## R5-WP5.9A implementation notes

- World interactables now share `WorldInteractionInput`, with non-consuming `E`/`Enter` press tracking plus pointer/tap binding. This avoids Phaser `JustDown` consumption when several world managers inspect the same press during one frame.
- Ordinary R5 region travel is movement-only. Crystal Cascade remains an explicit interactive race gateway.
- Dialogue/activity returns use `WorldArrivalState` plus the existing mutable map spawn points to preserve exact world position and facing without changing the save schema.
- Representative older Glade/Village/Meadow gateway spawn setters also establish sensible arrival facing.
- Collision-aware click navigation now includes Crystal Brook and Whispering Woods. Click navigation records player facing so later dialogue/activity returns remain correct.
- The exploration Controls panel is the current blocking modal for movement. It is identified explicitly rather than by UI depth, so transient feedback/toasts do not incorrectly freeze movement.
- `GALLOP` is a named input action. Keyboard default is held Shift, touch has an equivalent held control, and outdoor exploration uses the locked 1.6x speed multiplier through `PlayerEntity`, preserving normal Phaser collision/transition handling.
- No save-version change or migration was required for WP5.9A.

## R5-WP5.9B implementation notes

- The former exploration HUD ownership hidden inside `InteractionPrompt` has been split into a dedicated per-scene `ExplorationShell`. Interaction prompts now remain local interaction UI only.
- The shell owns Bag, Sound, Controls, suggestion/Hint, reward feedback and the shared touch pad. `ExplorationShell.ensure` makes shell creation idempotent so managers and older scenes cannot duplicate the common chrome.
- All current free-roaming exploration scenes use the same shell contract, including Crystal Brook and Whispering Woods. Story, race and activity scenes remain outside the shell allow-list.
- Crystal Brook and Whispering Woods retain their existing dedicated audio lifecycle; the shared Sound panel changes settings there without double-entering or double-leaving scene audio.
- Crystal Brook's two invisible middle-water blockers were removed because they crossed the visible stepping-stone/main-route corridor. The visible central stream is explicitly treated as shallow traversable water.
- The hard upper/lower pool collision rectangles were tightened inside the painted pools so the apparent banks and main path do not contain invisible rectangular corners.
- Brook and Woods route guidance is world-space rather than fixed HUD copy. The Brook text no longer implies a general exploration jump/hop mechanic.
- Geometry regression tests now protect major region spawns/gateway approaches, Crystal Brook stepping stones/main route and the Whispering Woods guiding-light route.
- No save-version change or migration was required for WP5.9B.
