## Implementation contract

The creator now owns a detached draft and explicit named control descriptors. Desktop and touch landscape use the six approved progressive categories and reveal only the selected category. Portrait uses the same six categories in a scrollable DOM surface, with its name and primary action in document flow. Selection state is read from the draft owner rather than inferred from rendered scale. Randomise preserves an existing name; reset and restore are distinct; no save occurs until the explicit confirmation command.

The profile appearance schema and every existing cosmetic ID remain unchanged. The same `UnicornAppearance` value feeds the preview renderer and persisted world renderer.
