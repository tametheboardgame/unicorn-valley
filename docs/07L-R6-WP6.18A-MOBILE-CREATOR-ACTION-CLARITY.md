# R6-WP6.18A - Mobile Creator and Action Clarity Remediation

Status: implemented on remediation branch, pending automated gate and merge.

## Why this remediation exists

The first R6-WP6.18 human playthrough exposed a bounded mobile usability cluster that should be corrected before the wider visual and traversal findings are addressed:

- the Unicorn Creator becomes cramped and difficult to read when the fixed game canvas is reduced to portrait phone width;
- creator controls need clearer grouping rather than presenting every option at once;
- the exploration interaction prompt is too easy to read as hint text rather than an action, particularly for the first Pip interaction;
- mobile action text needs to remain readable without taking space away from the play area itself.

This package deliberately does not absorb the separately observed world-art, Crystal Brook entrance presentation, placeholder-marker or point-and-click facing issues. Those remain independent remediation work so that this change stays reversible and reviewable.

## Implementation

### Portrait Unicorn Creator

- Added `CreatorPortraitControlsManager` using the same authoritative-control mirroring pattern already used by the portrait title screen.
- The original Phaser creator remains the source of truth for appearance state, save behaviour and desktop/landscape presentation.
- Portrait touch devices receive a large DOM control surface in the unused area below the 16:9 canvas.
- The mobile control surface contains:
  - a readable unicorn name field;
  - three mutually exclusive customisation sections: Colours, Hair & Tail, and Magic;
  - large labelled colour swatches;
  - 54 px previous/next controls for style choices;
  - the existing Surprise, Restore/Default, Cancel and Save/Confirm actions as appropriate to the current creator mode.
- Only one customisation section is expanded at a time, reducing visual density.
- The desktop creator and existing save/profile semantics are unchanged.

### Exploration action clarity

- `InteractionPrompt` now formats conversational actions naturally, including `Talk to Pip` instead of `Talk: Pip`.
- The in-canvas interaction prompt is slightly larger for improved legibility on compact landscape displays.
- Portrait touch exploration now mirrors the current interaction into a large DOM action card directly below the canvas.
- The card only appears while a non-automatic interaction is actually available and drives the existing `INTERACT` input path rather than bypassing gameplay logic.
- High-visibility interaction settings also apply to the portrait action card.

## Automated regression coverage

Added `tests/play/r6-wp6.18a-mobile-creator-action.spec.ts` covering the portrait touch compatibility projects:

- creator panel appears below the canvas;
- name field and major touch targets meet the intended minimum sizes;
- customisation sections collapse/expand correctly;
- colour/style selections still persist through the authoritative creator save path;
- approaching Pip surfaces a large `Talk to Pip` action;
- the mobile action drives the normal interaction input and clears when dialogue begins.

## Acceptance criteria

R6-WP6.18A is complete when:

1. formatting, lint, typecheck and unit checks are green;
2. production build/static smoke checks are green;
3. browser regression checks are green, including the new portrait tests;
4. existing desktop and landscape creator behaviour remains intact;
5. portrait creator controls are readable, grouped and comfortably tappable;
6. the first Pip interaction is presented as an obvious action button on portrait touch devices;
7. the remediation is merged to `main` without releasing the R6-WP6.18 hard stop.

## Hard-stop status

This package is a bounded R6-WP6.18 remediation only. It does not constitute R6-WP6.18 sign-off and does not release R7. Further playthrough findings remain to be triaged and corrected before the human-feedback gate can close.
