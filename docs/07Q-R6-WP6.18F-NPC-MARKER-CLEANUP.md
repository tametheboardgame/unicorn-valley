# R6-WP6.18F — NPC Marker Cleanup

## Purpose

Resolve the remaining human-playthrough defect where prototype circular NPC/interaction markers remain visible underneath production character art in Sunbeam Village.

The original prototype presentation draws a permanent 84 px stroked circle plus a simple icon at every village NPC marker. Later production-art presentation replaces Willow, Marigold and Pebble with authored character sprites, but the old circle was not removed, leaving a visible ring through/around the character art.

## Scope

- Hide the legacy prototype circle at Willow, Marigold and Pebble's world positions once their production-art presentation is active.
- Hide the corresponding prototype icon (`🌿`, `🥐`, `✦`).
- Keep the existing character name labels visible.
- Keep interaction targeting, prompts, story state, positions and collision behaviour unchanged.
- Do not remove the marker definition from map topology because those coordinates remain useful as authoritative NPC positions.
- Do not alter the deliberate framed portraits used in story scenes; those are presentation frames, not the reported world-marker defect.

## Implementation

`CoreNpcProductionPresentationManager` now owns the cleanup alongside the production-art replacement it already performs. A shared village marker cleanup checks only the exact NPC marker position and hides the small prototype `Arc` and prototype icon before/while the production sprite is installed.

Pebble is included explicitly; previously his secondary rock placeholder was hidden but the top-level village marker circle and sparkle remained.

## Regression coverage

`tests/play/r6-wp6.18f-npc-marker-cleanup.spec.ts` starts Sunbeam Village with browser diagnostics and verifies for Willow, Marigold and Pebble that:

- the production sprite exists and is visible;
- the original marker circle fixture still exists but is hidden;
- the original prototype icon exists but is hidden;
- the NPC name label remains visible.

This deliberately proves that the cleanup removes presentation residue without deleting the underlying marker topology.

## Hard-stop status

R6-WP6.18 remains an active human-playthrough hard stop after this remediation. R7 remains blocked until explicit playthrough sign-off.
