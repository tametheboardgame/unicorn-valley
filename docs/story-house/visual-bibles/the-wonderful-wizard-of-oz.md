# The Wonderful Wizard of Oz — modern Story House visual bible

Work package: **R6.5-WP19SH1.5.1**

## Approved set

The approved modern set contains **13 illustrations**: the original ten planned story beats plus
three useful long-form additions (Kansas cyclone, first giant-Head audience, and Lion acclaimed by
the forest animals).

The existing W. W. Denslow files remain the **Classic Illustrations** option. The generated set is
the independently selectable **Modern Illustrations** option.

## Approved visual language

The finished set uses a bright, polished animated-storybook / dimensional 3D illustration language:

- rounded, expressive character forms;
- cinematic depth and lighting;
- saturated Oz colours with a noticeably more restrained Kansas palette;
- stable recurring character silhouettes and costume colours;
- no collage layouts or multi-panel sheets;
- no baked-in captions, logos or UI.

This approved style supersedes the earlier exploratory gouache/watercolour direction.

## Source-design guardrails

- Follow Baum's public-domain novel rather than later screen adaptations.
- Dorothy's magical shoes are **silver**, never ruby.
- The Wicked Witch is human/pale-skinned rather than film-derived green-skinned, with a powerful
  eye and a visible golden cap.
- Oz's public illusion is an enormous theatrical/mechanical Head; the man behind it is an ordinary
  older showman.
- Dorothy returns to Kansas in **stocking-feet** because the silver shoes are lost in flight.

## Recurring character anchors

- **Dorothy:** auburn/brown braided hair with blue bows, blue-and-white checked dress, wicker basket,
  silver shoes while in Oz.
- **Toto:** small scruffy black terrier.
- **Scarecrow:** patched green/brown clothing, straw construction, floppy brown pointed hat.
- **Tin Woodman:** riveted silver body, funnel-like cap, axe; after Oz's gift, a small soldered square
  chest patch is visible.
- **Cowardly Lion:** warm tawny coat, large orange-brown mane, upright anthropomorphic posture in the
  accepted modern set.
- **Wicked Witch:** weathered human skin, dark hair, charcoal/plum robes, pointed dark hat with
  golden cap detail.
- **Glinda:** rich red hair, white gown with restrained ruby/red accents.

## Independent text / illustration contract

### Story House Edition

- Denslow mapping is `classic`;
- generated 13-image set is `modern`;
- default illustration set: `modern`.

### Full Classic Text

- Denslow mapping is `classic`;
- the same generated files are reused at matching Full Classic page/block anchors;
- default illustration set: `classic`.

The reader must support all four combinations:

1. Story House + Classic Illustrations;
2. Story House + Modern Illustrations;
3. Full Classic Text + Classic Illustrations;
4. Full Classic Text + Modern Illustrations.

## Human gate

The generated assets were individually reviewed during production. Final merge still requires the
13-image set to be viewed in the real reader as a sequence, including a Full Classic Text + Modern
Illustrations sample.
