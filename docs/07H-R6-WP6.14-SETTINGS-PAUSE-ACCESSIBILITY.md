# R6-WP6.14 - Settings, Pause and Accessibility Screen

## Goal

Make ordinary player settings calm, persistent and easy to reach from both the title experience and safe exploration, without mixing destructive save actions into the same surface.

## Implemented scope

- The existing title Settings overlay remains the authoritative front-door settings route.
- A reusable `SettingsScene` provides the full settings surface from exploration while safely pausing and resuming the current scene.
- The established exploration sound panel remains available for quick sound changes and now exposes a child-sized `More settings` action.
- Shared settings presentation covers:
  - all sound;
  - music;
  - ambience;
  - effects;
  - reduced motion;
  - high visibility;
  - fullscreen where the browser permits it.
- Full settings controls support pointer/touch plus Up/Down, Enter/Space and Escape keyboard interaction.
- The title settings overlay gains the same fullscreen capability plus visible keyboard selection without changing title save/routing behaviour.
- Portrait-phone title settings mirror the fullscreen control through the existing physical-size DOM controls.
- Audio and accessibility choices continue using their established local persistence stores and survive reloads.
- Fullscreen is treated as a browser/session capability rather than a saved game preference.
- No New Game, reset, import/export, account or destructive save action appears inside the settings surfaces.

## Text speed boundary

WP6.14 does not add a fake text-speed preference. Current dialogue cards render their complete line immediately rather than using timed reveal/typewriter presentation, so there is no meaningful dialogue speed to control safely yet. If WP6.15 introduces timed dialogue presentation, text speed can be added there against a real behaviour contract.

## Compatibility contract

- Save schema and progression data are unchanged.
- Existing quick audio controls and their diagnostic names remain intact.
- Existing title Settings behaviour remains available to pointer/touch users.
- Reduced Motion and High Visibility keep their existing storage key and semantics.
- SettingsScene is modal: exploration is paused, not restarted, and resumes at the same state when settings close.

## Verification

- Unit coverage validates shared labels, fullscreen capability presentation and keyboard selection wrapping.
- Browser coverage validates title keyboard selection, persistence across reload, the in-game pause/settings/resume route, persisted audio/accessibility choices, and child-sized full settings targets.
- Existing title phone regression coverage now includes the fullscreen mirror.
- The full repository CI/browser/browser-family gate remains mandatory before merge.
