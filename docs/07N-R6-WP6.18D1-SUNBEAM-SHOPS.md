# R6-WP6.18D1 — Sunbeam Village shops and interiors

## Purpose

This bounded R6-WP6.18 remediation responds to the human playthrough finding that the Sunbeam Village shops looked underdeveloped and behaved like decorative facades rather than places the player could actually visit.

The wider R6-WP6.18 human-feedback hard stop remains active. This package does not release R7.

## Changes

### Authored shopfronts

Sunbeam Bakery, Twinkle & Thread and Story House now use a more authored storefront treatment with:

- layered roof, facade and trim;
- framed display windows;
- awnings and flower boxes;
- a visibly open, lit doorway and threshold;
- explicit entry cues rather than a decorative closed facade;
- distinct palette and identity retained for each building.

The existing map collider footprints and established village paths are preserved.

### Real interiors

All three buildings now enter `VillageInteriorScene` with distinct room presentation:

- **Sunbeam Bakery** — bakery counter, displayed treats and a small berry-bun interaction;
- **Twinkle & Thread** — accessory counter and shelf display;
- **Story House** — bookshelves, reading table and a small story interaction.

Leaving an interior returns to the village at the same shop approach point rather than resetting the player to the world entrance.

### Existing economy reused

Twinkle & Thread does not introduce a second shop implementation. Its `Browse accessories` action launches the established `ShopScene`, which continues to use `ShopService`, `ShimmerEconomyService`, existing stock, ownership rules and save compatibility.

Closing the shop resumes the Twinkle & Thread interior before the player returns to the village.

## Regression coverage

`tests/play/r6-wp6.18d1-sunbeam-shops.spec.ts` verifies:

1. all three village shopfronts expose authored wall, doorway and entry-cue presentation;
2. bakery, accessory shop and library each have distinct interior content;
3. Twinkle & Thread opens the real `ShopScene`;
4. closing the shop resumes the interior;
5. leaving the interior returns safely to Sunbeam Village.

## Boundary

This package does not change:

- Shimmer balance rules or shop prices;
- inventory schema;
- story or quest progression;
- village/world topology;
- the R6-WP6.18 hard-stop status;
- Crystal Brook, Whispering Woods or race gateway presentation, which remain in D2.

## Exit condition

D1 is complete when formatting, lint, TypeScript, unit tests, production build/performance budgets and browser playthrough gates are green and the change is merged to `main`. R6-WP6.18 then remains open for D2/E and any further human playthrough findings.
