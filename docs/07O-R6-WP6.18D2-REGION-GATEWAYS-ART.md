# R6-WP6.18D2 — Region gateways and Crystal Brook / Whispering Woods art

## Purpose

This bounded R6-WP6.18 remediation addresses the playthrough finding that the Crystal Brook, Crystal Cascade and Whispering Woods entrances read like temporary portals rather than authored parts of the world, and that Crystal Brook / Whispering Woods needed a stronger environment-art pass.

The wider R6-WP6.18 human-feedback hard stop remains active. This package does not release R7.

## Gateway treatment

### Rainbow Meadow → Crystal Brook

The existing transition location remains compatible with the established R5 traversal logic, but its environmental reading is substantially changed:

- a separate curved southern branch now leaves the Meadow route and travels away from the race-hub presentation;
- vegetation visually separates the branch from the race space;
- the destination is an authored rocky cave mouth with a dark opening, boulders and crystal glints;
- the cave sits low in the Meadow and reads as somewhere the path physically enters rather than as a UI portal.

### Crystal Brook → Whispering Woods

The eastward route now has a dedicated narrower trail terminating in an intertwined tree/leaf threshold. Mushroom and foliage detail makes the change of biome legible before the scene transition.

### Crystal Brook → Crystal Cascade

The race entrance now has a separate rising branch from the Brook path and a purpose-built crystal race gate with water/crystal language and a clear `CRYSTAL CASCADE` identity. Existing unlock, interaction and race-selection semantics remain owned by `R5RegionGatewayManager`.

### Return thresholds

The Brook's Meadow return and the Woods' Brook return receive matching authored rock/woodland thresholds so travelling back no longer reveals the old gateway language as the dominant presentation.

## Region art tightening

### Crystal Brook

The remediation layer adds:

- larger cliff and rock shelves;
- distributed crystal clusters;
- a visible east-side cascade with water, foam and pool layering;
- stronger route separation between Brook exploration, Woods traversal and Crystal Cascade racing.

This complements rather than replaces the existing stream, stepping stones, treasure, production ambience and secret-route presentation.

### Whispering Woods

The remediation layer adds:

- larger foreground/background tree masses;
- denser canopy shapes;
- expanded mooncap/glow-plant clusters;
- stronger light shafts;
- an authored entry trail from the Brook threshold.

Existing discoveries, activity locations, colliders and progression remain unchanged.

## Architecture

`R6RegionGatewayArtManager` is presentation-only. It does not own transition rules, race unlocks, save checkpoints or destination spawning. Those remain in the existing R5 systems.

The manager is dynamically imported from `main.ts`, keeping the additional visual code out of the initial performance-budget entry chunk.

## Regression coverage

`tests/play/r6-wp6.18d2-region-gateways-art.spec.ts` verifies that:

1. the Meadow has a separate Crystal Brook branch and low cave mouth;
2. Crystal Brook exposes distinct Woods and Crystal Cascade paths/gateways;
3. the Crystal Brook production upgrade and cascade layer are present;
4. Whispering Woods has a woodland threshold, entry trail, denser forest layer and light shafts.

## Boundary

This package does not change:

- world topology or location IDs;
- R5 gateway transition distances;
- Crystal Cascade unlock/progression semantics;
- race physics or balance;
- discoveries or inventory;
- the R6-WP6.18 hard-stop status.

Crystal Cascade winability/balance remains R6-WP6.18E.

## Exit condition

D2 is complete when formatting, lint, TypeScript, unit tests, production build/performance budgets and browser playthrough gates are green and the change is merged to `main`. R6-WP6.18 then remains open for E and any further human playthrough findings.
