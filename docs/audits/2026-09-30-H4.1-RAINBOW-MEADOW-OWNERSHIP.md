# R6.5-WP19H4.1 - Rainbow Meadow ownership cleanup

Date: 30 September 2026

## Purpose

H4.1 removes superseded Rainbow Meadow presentation generations before the master-layout work begins. It is deliberately behaviour-preserving: no quest, race, save, Picnic Hill or Crystal Brook transition semantics move in this slice.

## Before-state ownership

The H4 audit confirmed overlapping ownership in the live Meadow:

- `RainbowMeadowScene` created the original path network, hand-built Nova, Nova label and west-gateway rectangle/label.
- `WorldTraversalPolishManager` drew a second main route and gateway, then hid the old west-gateway presentation.
- `ExplorationPathPolishManager` repainted the Meadow main route/spurs again.
- `VisualTighteningManager` hid the scene Nova and created a `NovaIdentity` replacement.
- `CoreNpcProductionPresentationManager` hid both older Nova generations before creating the authoritative presence-aware production Nova.
- `R6RegionGatewayArtManager` created a Meadow→Crystal Brook path/divider that `R6FinalPlaythroughCleanupManager` immediately hid and replaced with a corrected route.
- `WorldLayerAlignmentManager` retained Meadow-only logic solely to move the hidden divider.
- `WorldCharacterPresentationManager` existed only to resize/reposition the original Meadow Nova generation.
- `EnvironmentProductionPresentationManager`, `VisualTighteningManager` and `MeadowDepthWorldManager` still add valid Meadow-specific detail that later H4 composition slices must deliberately absorb or retain.

## H4.1 ownership after cleanup

- `RainbowMeadowLayout` is the source of truth for current structural Meadow coordinates, west gateway, race-hub anchors, Nova race-hub anchor, path network and the accepted current Crystal Brook route presentation.
- `RainbowMeadowMap` projects behavioural/navigation data from the canonical layout.
- `WorldTraversalPolishManager` is the sole owner of the current main Meadow path network and west gateway presentation; it retains the actual Sunbeam traversal behaviour.
- `CoreNpcProductionPresentationManager` is the sole current Meadow Nova presentation owner and retains `CoreNpcPresenceService` authority.
- `R6FinalPlaythroughCleanupManager` temporarily retains only the accepted current Crystal Brook route presentation. H4.4 will replace this legacy-named route ownership when the functional transition is deliberately relocated.
- `R6RegionGatewayArtManager` retains the current Crystal Brook cave threshold but no longer creates hidden path/divider residue.

## Removed residue

- scene-owned original Meadow path graphics;
- scene-owned old Nova and label;
- scene-owned west entrance rectangle/label;
- Meadow path repainting in `ExplorationPathPolishManager`;
- `VisualTighteningManager` Meadow Nova replacement;
- `CoreNpcProductionPresentationManager` hide logic for the removed race-hub Nova generations;
- `WorldCharacterPresentationManager` installation and implementation;
- old Meadow→Crystal Brook path/divider creation;
- cleanup-time hiding of those removed gateway objects;
- Meadow layer-alignment logic that existed only for the removed divider.

## Deliberately retained for later H4 slices

- Nova's current production art design is unchanged; H4.6 owns the redesign.
- Picnic Hill coordinates/presentation are unchanged; H4.5 owns the relocation/rebuild.
- Crystal Brook's functional transition remains at its existing coordinates; H4.4 owns the traversal relocation/canonicalisation.
- Meadow-specific atmosphere/detail from `EnvironmentProductionPresentationManager`, `VisualTighteningManager` and `MeadowDepthWorldManager` remains in place where it is currently visible and valid. H4.2/H4.7/H4.8/H4.10 will decide its final area-owned composition placement instead of moving it speculatively during cleanup.

## Verification contract

H4.1 adds unit coverage for the canonical layout and browser diagnostics coverage proving:

- one current production Nova;
- no `nova-canonical-world` replacement;
- no generic `exploration-path-polish` Meadow path;
- no old R6 Meadow→Crystal path/divider;
- the accepted corrected Crystal Brook route remains;
- the obsolete west-gateway rectangle is absent.

The visual checkpoint still requires a deployed preview and human approval before merge.
