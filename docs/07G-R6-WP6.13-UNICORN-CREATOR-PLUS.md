# R6-WP6.13 - Unicorn Creator Plus

## Purpose

R6-WP6.13 expands the stable modular unicorn customisation system into a richer, more playful creator without changing progression, reward balance or save schema.

The package builds directly on the safe single-profile redesign flow from R6-WP6.12. Existing cosmetic IDs remain valid and every new option is additive.

## Implementation

### Richer creator presentation

- the live unicorn preview is larger and more clearly framed;
- creator controls are grouped visually into Colours, Hair & Tail, and Magic Details;
- selected colour swatches receive stronger gold selection treatment;
- the preview panel has a clearer authored presentation rather than reading as a utility form;
- edit mode separates Surprise, Restore Saved and Default Look actions so experimentation remains reversible.

### Expanded cosmetic catalogue

The data-driven catalogue now includes:

- eight body colours;
- six eye colours;
- eight mane/tail colours;
- five mane styles;
- five tail styles;
- five horn styles;
- six markings;
- seven accessories.

New options include Peach, Buttercup and Pearl body colours; Lilac, Coral and Ice hair; Moon Braid and Star Crest manes; Moon Braid and Cloud Puff tails; Little Horn and Crystal Tip horns; Freckles and Sparkles markings; and Tiny Crown, Neck Ribbon and Cosy Scarf accessories.

### Production renderer support

Every new style has an explicit procedural production-art rendering path. New IDs are therefore visible consistently in the creator and normal gameplay rather than existing only as menu labels.

Geometry remains inside the established production texture frame, including raised crown/crystal details and extended braided hair/tail forms.

### Safe naming and randomisation

- creator name input explicitly stops gameplay-key keyboard events from propagating;
- Phaser global keyboard capture remains disabled while the HTML name field is active;
- randomisation draws from the complete registered cosmetic catalogue;
- randomising an existing unicorn changes appearance only and does not unexpectedly rename the saved character;
- Default Look in redesign mode resets appearance while leaving the typed name alone;
- Restore Saved restores both saved appearance and saved name.

### Data-driven validation

`UNICORN_COSMETIC_REGISTRY` is the canonical creator catalogue. Validation rejects blank IDs, blank labels and duplicate IDs, and unit coverage verifies the expanded catalogue can round-trip through the existing save appearance map.

No save-schema bump is required.

## Browser coverage

Dedicated production-browser regression coverage verifies:

- the richer category/preview presentation is exposed;
- names containing ordinary gameplay-key letters can be entered and saved;
- a new Creator Plus body colour serialises correctly;
- existing profiles can save new mane, tail, horn, marking and accessory IDs while preserving adventure state;
- Default Look leaves an edited name untouched;
- Restore Saved recovers the complete saved profile.

## Scope boundary

This package does not add unlock requirements, shops, currency costs, wardrobe progression, saved-look slots or gameplay bonuses for cosmetics. Those remain daughter-led expansion decisions for R7 if real play behaviour justifies them.

R6-WP6.14 remains the next package after this work is validated and merged.
