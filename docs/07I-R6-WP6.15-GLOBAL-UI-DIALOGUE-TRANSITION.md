# R6-WP6.15 - Global UI, Dialogue and Transition Polish

## Status

Implementation complete pending validation and review.

## Purpose

This package removes remaining presentation inconsistency from stable dialogue and storybook UI flows without changing story data, progression, save state or gameplay timing.

## Implemented scope

- the shared `DialogueCard` now uses the canonical production portrait renderer for Nova, Willow, Pip, Pebble, Lumi and Marigold;
- non-core speakers retain the existing readable letter portrait fallback;
- core portrait frames inherit the character's established production palette rather than introducing a second visual identity;
- dialogue lines expose explicit `Enter / tap to continue` guidance alongside the existing large Continue control;
- choice nodes expose clear selection guidance while retaining the existing pointer/touch buttons and keyboard default-choice contract;
- dialogue body changes use only a brief visual alpha settle, with the complete text available immediately;
- the Continue indicator receives restrained motion when motion is permitted and becomes completely static under Reduced Motion;
- shared Bag, Shop, Cottage Decorating and Wonderbook ornaments no longer animate when Reduced Motion is enabled;
- production objects receive stable diagnostic names so visual behaviour is regression-testable;
- new browser coverage verifies canonical Lumi portrait use, non-core fallback behaviour and static Reduced Motion ornament presentation.

## Deliberate boundaries

WP6.15 does not add typewriter text or a text-speed setting. Dialogue still renders complete lines instantly, so introducing timed reveal solely to justify a setting would add behaviour and timing risk without evidence that the target player wants it.

WP6.15 also does not change:

- dialogue wording or branching;
- quest or relationship progression;
- save schema or persistence;
- scene routing;
- race or movement timing;
- destructive actions;
- gameplay input mappings.

## Validation gate

Before merge the final PR head must pass:

- formatting and lint;
- TypeScript checking;
- unit tests;
- production build and performance budgets;
- static smoke;
- complete Chromium browser regression;
- exact-head Cloudflare Pages preview;
- review findings resolved or explicitly dispositioned.

## Acceptance

WP6.15 is accepted when core dialogue presentation is visually consistent with the production NPC art, fallback speakers remain readable, Reduced Motion suppresses the new and existing decorative motion covered by this package, and all existing gameplay/progression regressions remain green.

R6-WP6.16 follows with the bounded Front-End Art, Ambience and Audio Delight Pass.
